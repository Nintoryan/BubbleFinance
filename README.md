# Bubble Finance - Домашний финансовый трекер

Полнофункциональное приложение для отслеживания семейных финансов, созданное с использованием Next.js, TypeScript, Prisma и SQLite.

## 🚀 Технологии

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Tremor** (графики и дашборд)
- **Prisma** (ORM)
- **SQLite** (база данных)
- **Docker** (контейнеризация)

## 📋 Функционал

- ✅ Авторизация через PIN-код
- ✅ Управление счетами (создание, редактирование, удаление)
- ✅ Управление категориями доходов и расходов
- ✅ Создание и отслеживание транзакций
- ✅ Конвертация валют (USD, EUR, RUB, RSD, VND)
- ✅ Аналитика с графиками:
  - Динамика баланса
  - Расходы и доходы по дням
  - Расходы по категориям (круговая диаграмма)
- ✅ Импорт/экспорт транзакций в CSV
- ✅ Мобильная оптимизация

## 🛠️ Установка и запуск

### Локальная разработка

1. **Клонируйте репозиторий** (или используйте текущую директорию)

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Создайте файл `.env`** на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```

4. **Настройте `.env`:**
   ```env
   APP_PIN=123456
   DATABASE_URL="file:./data/dev.db"
   ```

5. **Инициализируйте базу данных:**
   ```bash
   npm run setup
   ```
   
   Или пошагово:
   ```bash
   npm run prisma:generate
   npm run prisma:migrate
   npm run prisma:seed
   ```

6. **Запустите dev-сервер:**
   ```bash
   npm run dev
   ```

7. **Откройте браузер:**
   ```
   http://localhost:3000
   ```

### Запуск через Docker

1. **Создайте файл `.env`** с настройками:
   ```env
   APP_PIN=123456
   DATABASE_URL="file:./data/dev.db"
   ```

2. **Соберите и запустите контейнер:**
   ```bash
   docker-compose up --build
   ```

3. **Приложение будет доступно по адресу:**
   ```
   http://localhost
   ```

> **Примечание:** База данных SQLite будет храниться в директории `./data`, которая монтируется как volume в Docker.

## 📝 API Endpoints

### Авторизация
- `POST /api/login` - Вход по PIN
- `POST /api/logout` - Выход

### Счета
- `GET /api/accounts` - Список счетов
- `POST /api/accounts` - Создать счёт
- `PUT /api/accounts/:id` - Обновить счёт
- `DELETE /api/accounts/:id` - Удалить счёт

### Категории
- `GET /api/categories?type=INCOME|EXPENSE` - Список категорий
- `POST /api/categories` - Создать категорию
- `PUT /api/categories/:id` - Обновить категорию
- `DELETE /api/categories/:id` - Удалить категорию

### Транзакции
- `GET /api/transactions?from=...&to=...&type=...&accountId=...` - Список транзакций
- `POST /api/transactions` - Создать транзакцию
- `PUT /api/transactions/:id` - Обновить транзакцию
- `DELETE /api/transactions/:id` - Удалить транзакцию

### Статистика
- `GET /api/stats/overview?from=...&to=...&baseCurrency=...` - Общая статистика

### Настройки
- `GET /api/settings` - Получить настройки
- `PUT /api/settings` - Обновить настройки

### Импорт/Экспорт
- `GET /api/export/transactions?from=...&to=...` - Экспорт CSV
- `POST /api/import/transactions` - Импорт CSV

## ⚠️ Важные замечания

1. **Безопасность**: PIN-код хранится в открытом виде в `.env`. Это домашний проект, не используйте его для критически важных данных без дополнительной защиты.

2. **База данных**: SQLite файл хранится в `./data/dev.db`. Убедитесь, что эта директория доступна для записи.

3. **Курсы валют**: Используется бесплатный публичный API. При отсутствии интернета используются fallback-курсы.
